# Bibliography source and historical audit notes

`REFERENCES.bib` is a byte-identical copy of the bibliography-corrected
RC0.2 internal audit bibliography. Some research-audit `note` fields explicitly
refer to **RC0.1**, the earlier English draft being reviewed by Claude;
those are historical cross-references, not claims that this public v0.2
report has not yet adopted the corrections. The actual report citations
are the 16 `\bibitem` entries in the compiled TeX file.

The public report is derived from RC0.2, with only GitHub-specific publication
labels and disclosure paragraphs changed. Do not assume the audit verified
all historical or third-party claims across the entire cumulative notebook.
