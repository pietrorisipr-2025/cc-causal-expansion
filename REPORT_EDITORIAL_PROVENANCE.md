# Short English report: editorial provenance

The GitHub v0.2 short English report is based on the bibliography-corrected
Zenodo RC0.2 *internal candidate* source, which was never itself published.
For a public GitHub archive the version/date line, status notices,
AI/human accountability paragraph and Zenodo-specific deposit restrictions
were changed to GitHub public-archive language. The main scientific section
and all 16 inline bibliography entries are **text-identical** to RC0.2.
The bibliography file `report/REFERENCES.bib` is copied byte-for-byte from
RC0.2. The v1.03 cumulative notebook PDF, LaTeX source and all 104 figures
are **not editorially edited** in this package.

The report is a selective overview, not a full translation or a new theorem.
Scientific novelty and peer review are not claimed. The available English
summary does not imply all 374 pages were checked independently by humans.
